# Hospital Management System 🏥

A professional, full-stack Hospital Management System designed to streamline healthcare operations. This project features a modern **React** frontend and a robust **Django** backend.

## 🚀 Overview
This system provides a comprehensive platform for managing patients, appointments, and administrative tasks. It aims to improve the efficiency of hospital workflows and enhance the patient experience through a clean, intuitive interface.

## 🛠️ Tech Stack
- **Frontend**: React.js, Vite, CSS3
- **Backend**: Django, Django REST Framework (DRF)
- **Database**: SQLite (Development)
- **Authentication**: JWT / Session-based

## ✨ Key Features
- **Patient Dashboard**: Manage profiles and view medical history.
- **Appointment Management**: Seamless booking and scheduling system.
- **Admin Panel**: Comprehensive oversight for hospital administrators.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## 📂 Project Structure
- `hospital/myhospitalreact/`: React frontend application.
- `hospital/MY_HOSPITAL/`: Django backend application.

## 🔧 Installation

### Backend Setup
1. Navigate to the backend directory.
2. Install dependencies: `pip install -r requirements.txt` (if applicable).
3. Run migrations: `python manage.py migrate`.
4. Start server: `python manage.py runserver`.

### Frontend Setup
1. Navigate to `hospital/myhospitalreact/`.
2. Install dependencies: `npm install`.
3. Start development server: `npm run dev`.
